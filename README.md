# Gestão de Contratos - React Native

Front-end desenvolvido em React Native com Expo para o projeto de Gestão de Contratos da Avaliação A3 da disciplina de Sistemas Distribuídos e Mobile.

## Sobre o projeto

Este aplicativo consome uma API REST desenvolvida em Django Rest Framework e permite gerenciar as principais entidades do sistema de contratos.

## Tecnologias utilizadas

- React Native
- Expo
- TypeScript
- React Navigation
- Consumo de API REST

## Funcionalidades

O sistema possui telas para cadastro, listagem, edição e exclusão de:

- Clientes
- Funcionários
- Usuários
- Canais de contato
- Categorias de contrato
- Serviços
- Contratos
- Itens de contrato
- Pagamentos
- Documentos
- Notificações
- Auditorias
